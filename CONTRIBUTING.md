# Contributing

Open an issue before a substantial change so maintainers can agree the scope. Keep pull requests focused, describe the behavior before and after, and include meaningful regression tests for changed behavior.

For security controls, state the threat model, what the control enforces, and what it does not cover. Do not claim a protection without a reproducible test. Use synthetic data; never contribute credentials, customer records or employer-owned material.

Each project's license and contribution guidance take precedence. Report exploitable vulnerabilities privately using SECURITY.md.
