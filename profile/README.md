## What we do

We review AI workflows, APIs and cloud deployments, investigate trust boundaries, and help implement practical controls. Start with a narrowly scoped system and leave with evidence, prioritized fixes and clear limits.

Final scope, schedule and applicable taxes are agreed in writing. Cloud/model costs, certification, compliance attestation, 24/7 monitoring and incident response are outside these packages.

## Open source: X0R Core

[Core](https://github.com/X0R-labs/core) is an experimental, self-hosted Python backend with text ingestion, retrieval, workspace API keys, bounded agent execution, usage accounting and basic evaluation suites.

Security development priorities include tool authorization, safer execution evidence, resource controls and adversarial regression tests. Check the repository and pull requests for implemented behavior and known limitations. Mock-provider demos demonstrate orchestration; they do not establish real-model security or deployment readiness.

## Research interests

AI agent security, execution provenance, applied cryptography and secure distributed systems. We distinguish observed execution paths from proven causal attribution.
