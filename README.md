# X0R Labs organization defaults

`profile/README.md` is the public organization overview. `CONTRIBUTING.md`, `SECURITY.md` and `PULL_REQUEST_TEMPLATE.md` provide reusable contributor guidance.

Issue templates and their configuration live in `.github/ISSUE_TEMPLATE/` inside this repository. GitHub can use these defaults for organization repositories that do not define their own templates. Project-specific files take precedence.

Website: https://x0r-labs.github.io/site/
